# pairwise-projectile-ballistics

远程武器在高速移动目标上命中判定漂移，服务器用当前位置做射线检测，客户端却按开火瞬间的旧位置显示命中；子弹穿透只按命中次数扣减，没按材质厚度和入射角衰减；投射物用可变 dt 积分，低帧率下穿过薄墙；重力下坠在客户端预测和服务端校正各算一套，落点差半米；护盾先于实体碰撞结算，穿盾子弹被错误吞掉；多发霰弹在同一帧结算，后坐力叠加顺序不确定；延迟补偿只回滚玩家位置，没回滚可破坏物状态；子弹在移动平台坐标系里积分，平台移动后弹道整体偏移；回放只记录命中点没记录穿透路径，重放看不到子弹穿墙；网络丢包重发时同一发子弹被结算两次。gameplay/projectile_ballistics.py 是核心，tests/test_projectile_ballistics.py 15个红。要修的是：服务器按开火帧位置回溯；穿透按厚度与角度衰减；固定子步积分；客户端与服务端共用重力；护盾与实体按层排序；霰弹按稳定顺序结算；回滚含可破坏物；弹道在平台局部系积分；回放存完整路径；子弹唯一 id 幂等。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
